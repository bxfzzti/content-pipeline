# 挑战认知型选题模式（已验证高流量）

## 核心公式

「大家以为A，其实B」——用事实数据颠覆共识。

**为什么有效：**
- 读者看到标题会想"不可能吧？"→ 点进来看
- 看完后会想"确实诶"→ 点赞/收藏
- 或者"不对！"→ 评论反驳（评论也是流量）

## 选题方法

发布会/热点事件后，不要只写产品本身，而是问自己：
1. 这个事件颠覆了什么"常识"？
2. 谁会因为这个事实而"难受"？
3. 大家以为的因果关系，是不是反的？

## 已验证案例

### 案例1：宝马砍掉所有国产纯电（2万+阅读）
- 常识：宝马是豪华品牌，电动化是未来
- 反转：宝马主动砍掉国产纯电，不是"放弃"而是"止损"
- 反差：40万的宝马i3降价到20万还是卖不动，不如直接停掉

### 案例2：理想纯电比增程卖得好
- 常识：理想只会做增程，纯电是短板
- 反转：理想i6四个月卖8.6万辆，增程L系列反而停产换代
- 反差：最不被看好的纯电线，反而撑起了销量

### 案例3：比亚迪大唐 = "半价理想"从零跑手里抢走
- 常识：零跑是"半价理想"的代名词
- 反转：比亚迪大唐23.99万，配置比零跑D19更强
- 反差：零跑做了三年的标签，被比亚迪一巴掌打醒

### 案例4：便宜电车反而卖不动
- 常识：中国市场只要便宜就不愁卖
- 反转：8万以下新能源车销量暴跌50%
- 反差：购置税新政2000块税费就能劝退一批人

## 结构模板（900字以内）

```
第1段（2-3句）：抛出"常识" + 我要颠覆它
  "过去X年，所有人都说A。但最近的数据告诉我，B。"

第2-3段（各5-8句）：用数据/事实证伪"常识"
  对比表格、具体数字、竞品数据

第4段（3-4句）：解释"为什么会反转"
  深层原因（政策变化/成本结构/用户行为变迁）

第5段（2-3句）：金句收尾
  "X做了三年的Y，被Z一巴掌打醒了"
  "真正的输家不是A，是B"
```

## 注意事项

- 反转必须有数据支撑，不能瞎编
- 竞品必须引入，单品牌叙事缺乏说服力
- 金句放最后一段（截图传播用）
- 话题标签：核心品牌 + 竞品品牌 + 品类词 + 争议词
