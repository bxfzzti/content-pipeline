# 多Agent信息传递格式规范

## 1. 主Agent → 筛选Agent

主Agent传给筛选Agent的信息必须包含两个部分：热点数据 + 内容定位。

### 格式模板

```
## 热点数据

[每个热点一条，格式如下]
- 编号: [数字]
- 标题: [一句话描述]
- 来源: [平台名称，如IT之家、微博、知乎]
- 时间: [今天/昨天/N天前]
- 平台数: [几个平台在讨论]
- 情绪强度: [高/中/低，如有评论数据可补充说明]
- 关键数据: [核心数字或事实]

## 内容定位

- 目标读者: [描述目标读者的特征]
- 核心领域: [汽车/科技/行业分析/社会热点等]
- 平台: [小红书/公众号/抖音等]
- 内容风格: [观点表达/深度分析/产品评测等]
```

### 示例

```
## 热点数据

- 编号: 1
- 标题: 沃齐尼亚——40岁佛得角门将，7次扑救逼平西班牙
- 来源: 微博、知乎、抖音
- 时间: 今天
- 平台数: 3
- 情绪强度: 高（赛后哭泣、凑不齐签证保证金，评论区大量情感共鸣）
- 关键数据: 40岁、5万欧元身价、7次扑救、ins粉丝从4万涨到800万

- 编号: 2
- 标题: 理想Livis Day——具身智能定义发布
- 来源: IT之家、36氪
- 时间: 昨天
- 平台数: 2
- 情绪强度: 中（主要是信息传递，讨论不激烈）
- 关键数据: 马赫VLA、0.28秒反应速度、OTA三波升级

## 内容定位

- 目标读者: 关注汽车/科技/行业分析的中产男性（30-45岁）
- 核心领域: 汽车评测、行业趋势、科技产品分析
- 平台: 小红书
- 内容风格: 观点表达（有立场的判断型内容）
```

## 2. 筛选Agent → 主Agent

筛选Agent输出的每个选题必须包含以下字段：

### 格式模板

```
## 选题[N]: [一句话描述]

热度评分: XX/40分
- 时效性: X/5（[判断依据]）
- 讨论热度: X/5（[判断依据]）
- 情绪强度: X/5（[判断依据]）
- 内容关联度: X/5（[判断依据]）

切入方向:
1. [方向类型]方向: [具体怎么切入]
   - 适合什么读者: ...
   - 需要补充的事实: ...
   - 预期阅读体验: ...

不值得写的理由: [按严重程度排序]
推荐理由: ...
差异化建议: ...
```

## 3. 主Agent → 结构Agent

主Agent传给结构Agent的信息必须包含三个部分：事实材料 + 读者已知信息 + 筛选Agent的切入方向。

### 格式模板

```
## 事实材料

[每个事实点一条，包含具体数字/细节]
- [事实1]
- [事实2]
- ...

## 读者已知信息

- 已知: [读者已经知道什么]
- 未知: [读者不知道什么]

## 筛选Agent切入方向

- 方向类型: [故事方向/分析方向/预判方向/站队方向/类比方向]
- 具体切入: [怎么切入]
- 需要补充的事实: [哪些事实需要展开]
```

### 示例

```
## 事实材料

- 沃齐尼亚: 40岁，佛得角门将，身价5万欧元
- 2026世界杯小组赛，佛得角0:0逼平西班牙（世界排名第2）
- 做出7次扑救，当选全场最佳
- 赛后哭着说凑不齐妈妈来美国看球的15000美元签证保证金
- ins粉丝从4万一夜涨到800万
- 阿尔奥维斯: 沙特门将，身价70万欧元（梅西的1/70）
- 2022世界杯小组赛首轮，沙特2-1击败阿根廷（世界排名第3）
- 做出5次关键扑救，当选全场最佳
- 2026世界杯他仍在沙特阵中，34岁

## 读者已知信息

- 已知: 沃齐尼亚的故事（2026世界杯当下热点）
- 未知: 阿尔奥维斯的故事（2022世界杯历史案例）

## 筛选Agent切入方向

- 方向类型: 类比方向
- 具体切入: 从沃齐尼亚联想到阿尔奥维斯，两个小国门将的故事
- 需要补充的事实: 阿尔奥维斯的背景、2022年世界杯沙特vs阿根廷的细节
```

- 未知: ...

## 结构方案一: [一句话描述]

框架: [框架名称]（主框架）+ [子框架名称]（如适用）
切入点: ...

逻辑链:
  第一步: ...
  第二步: ...
  第三步: ...
读者体验: ...
优缺点: ...

## 推荐: 方案X

理由1（适配性）: ...
理由2（信息效率）: ...
理由3（传播性）: ...

## 自检清单

- [ ] 读者已知信息已明确标注

## 5. 主Agent → 质检Agent

主Agent传给质检Agent的信息必须包含：文章正文 + 事实材料。

### 格式模板

```
## 文章正文

[完整的文章内容]

## 事实材料

[用于核查文章中引用的数据/事实]
- [事实1 + 来源]
- [事实2 + 来源]
- ...
```

## 6. 质检Agent → 主Agent

质检Agent输出必须按L1-L4逐层报告，每个问题给出具体修复建议。

### 格式模板

```
## 质检报告

### L1 硬性规则 ✅/❌

**禁用词：**
- [具体位置] 一处"xxx" → 建议改成"xxx"

**设问句：**
- 共出现X处设问句 → 建议保留第X个，其余改成陈述句

**新文体反模式：**
- [具体位置] 一处设问引导"xxx" → 建议改成"xxx"

**事实核查：**
- ✅ [具体数据] 验证通过（来源：xxx）
- ❌ [具体数据] 错误，正确数据是xxx（来源：xxx）
- ⚠️ [具体数据] 待验证，找不到原始出处

**禁用标点：**
- [具体位置] 一处冒号段落 → 建议改成逗号句号

### L2 风格一致性 ✅/❌

**开头：** ✅/❌ [具体说明]
**节奏：** ✅/⚠️ [具体说明]
**口语化：** ✅/⚠️ [具体说明]

### L3 内容质量 ✅/❌

**观点支撑：** ✅/❌ [具体说明]
**知识输出：** ✅/❌ [具体说明]
**支柱类比：** ✅/❌ [具体说明]
**跨域类比：** ✅/❌ [具体说明]
**对立面理解：** ✅/❌ [具体说明]

### L4 活人感 ✅/❌

**整体感觉：** 像真人写的 ✅/❌
**情绪表达：** 体感记忆 ✅/知识性描述 ❌
**角度独特性：** ✅/❌
**注意力断点：** 无/X处

### 总评

**通过层数：** X/4层通过
**事实错误：** X处（必须修）
**风格问题：** X处（建议修）

**修复优先级：**
1. [最需要修的问题 + 具体修复方式]
2. [第二需要修的问题 + 具体修复方式]
3. [第三需要修的问题 + 具体修复方式]

### 自检清单

- [x] 逐层检查了L1-L4
- [x] 关键数字用web_search验证
- [x] 每个问题给出了具体修复建议
- [x] 输出格式符合模板
- [x] 区分了事实错误和风格问题
```

## 使用规则

1. **主Agent负责组装信息**：主Agent从各个来源（热点数据、搜索结果、筛选Agent输出）收集信息，按格式组装后传给子Agent。
2. **子Agent必须按格式输出**：子Agent不能自创格式，必须按上方的格式模板输出。
3. **信息缺失时先问**：如果子Agent发现输入信息缺失关键字段，必须先向主Agent提出，不能自己编造。
4. **输出可直接被下一个Agent使用**：筛选Agent的输出可以直接作为结构Agent的输入，不需要主Agent重新整理。
5. **质检Agent→修复Agent的传递**：质检Agent的质检报告直接传给修复Agent，修复Agent按严重程度排序修复后输出修复报告+修复后的文章。
6. **修复后必须重新质检**：修复Agent输出后，主Agent将修复后的文章重新提交给质检Agent做最终确认。
