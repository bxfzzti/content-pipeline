# 小红书商业内容写法指南

## 核心原则：体验向，不是广告向

用户明确要求：商业合作内容**不能像广告贴**，要像真实体验分享。

### 错误示范（播报员/广告视角）

```
启境GT7相关的两类门店首批上线，体验与服务网络加速落地，
预计6月底覆盖全国70城、超300家门店。
```

问题：直接播报新闻，没有调起用户对车的兴趣，逻辑是"信息→信息→信息"。

### 正确示范（体验者视角）

```
最近被启境GT7刷屏了，预售21.99万起，乾崑满配宁德标配，
这个配置这个价格说实话我挺好奇的，就想着去店里看看实车。

结果到了才发现——进错店了 😂
```

逻辑是：**好奇→行动→踩坑→总结经验→讲车→对比→建议**

### 叙事结构模板

1. **钩子**：以个人好奇心/体验切入，不是以品牌新闻切入
2. **踩坑/发现**：在体验过程中发现了一个有价值的信息（如两类门店）
3. **干货**：把踩坑经验转化为读者能用的信息
4. **产品分析**：从体验者角度讲车的优劣势
5. **竞品对比**：和同价位竞品横向比较
6. **建议**：帮读者做决策

### 金句

> 把两个事情全部讲起来了，想起来是一个真实的体验分析，而不是一个广告贴。

## 品类适用

- 汽车门店/新车上市 → 先讲自己好奇想去看，再带出门店/产品信息
- 好物推荐 → 先讲自己的使用场景和痛点，再引出产品
- 品牌活动 → 先讲自己参加了什么，有什么意外发现，再讲品牌信息

## 合规内容的融入技巧

品牌方给的硬性要求（价格、门店信息、CEO金句等）不能丢，但要**嵌入体验叙事中**，不要单独拎出来当播报。

- ❌ "启境CEO原话：研发Ready、工厂Ready、渠道Ready、服务Ready"（生硬植入）
- ✅ "启境CEO原话：研发Ready、工厂Ready、渠道Ready、服务Ready。（放在讲完车本身之后，作为总结背书）"
