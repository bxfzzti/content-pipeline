# 小红书内容优化

小红书也可以写长文。本skill不是「把公众号文章搬到小红书」，而是**让小红书内容从一开始就适配平台算法和用户习惯**——标题、封面图、关键词、正文结构、发布节奏，全方位优化。

## 内容定位

**@村长不开车 的小红书内容不是种草、不是评测，是「有立场的观点表达」。**

特点：
- 有明确判断（「Model Y不值26万」「L8砍掉第三排反而更值」）
- 判断会引发争议（特斯拉粉丝反对、理想粉丝质疑）
- 争议引流量，论据撑观点
- 历史类比是核心手法（「特斯拉=几年前的BBA」）

这类内容在小红书上是稀缺的——大部分汽车内容是种草/评测/价格对比，敢于下判断的少。**争议本身就是流量。**

## 什么时候用

- 写小红书内容时（不管是长文还是短文）
- 用户说「发小红书」「小红书标题」「封面图」「小红书优化」
- 发布会/热点事件后需要快速发小红书

## ⚠️ 重要前置知识

- **用户只写小红书，不写公众号。** 小红书也可以写长文（800-2000字）。不要把本skill定位为「公众号→小红书适配」，它是「小红书内容优化」。
- **用户的小红书内容定位：有立场的观点表达**（争议判断+历史类比+论据支撑），不是种草/评测。
- **写作风格参照 writing-style skill 的角色卡**（观察者型行业老兵），不要用公式化的XHS爆款模板。
- **已研究的5个外部工具（dbs-xhs-title/write-xiaohongshu/xhs-writer/MediaCrawler/xhs-studio）用户要求废弃**，不纳入本skill。用原生活人感风格。

## 核心逻辑

小红书用户刷信息流的速度是每秒2-3条。决定用户点不点进去的，是**封面图+标题**，不是正文质量。

| 维度 | 小红书长文 | 小红书短文 |
|------|-----------|-----------|
| 字数 | 800-2000字 | 300-800字 |
| 封面图 | 极其重要 | 极其重要 |
| 标题 | 冲突感/好奇心/个人体验 | 同左 |
| 结构 | 观点→展开→金句 | 观点→支撑→判断 |
| 搜索权重 | 高（长文搜索流量更大） | 中 |
| 适合场景 | 深度分析、产品评测、体验分享 | 快速反应、观点表达、种草 |

## 执行步骤

### Step 0：交付方式

**用户说"发这里"或"写完直接发我"时，正文直接在对话中输出，不要只存文件。** 文件可以同时保存，但正文必须在消息中发送。

**字数控制：** 默认不超过900字（用户明确要求过"不高于900字"）。除非用户指定"长文"或"深度帖"，否则按短文节奏写。

### Step 1：提炼核心观点

从文章/素材中提取：
- 1个核心结论（一句话能说清）
- 1个冲突点/争议点（让人想点进来看）
- 1个跟用户有关的角度（「跟我买车/买手机有什么关系」）
- 3-5个关键数据点（价格、配置、对比）

**竞品必须引入：** 写任何产品/品牌时，不要只聊单一产品。把同价位/同赛道的竞品拉进来一起对比（如写比亚迪大唐，必须引入零跑D19；写理想纯电，必须提增程的对比）。竞品对比让观点更有说服力，也更容易引发讨论。

### Step 2：生成小红书标题（5选1）

用 writing-style skill 的活人感体系生成标题，不用外部公式工具。

**小红书标题方向（按爆率排序）：**

**0. 挑战认知型（爆率最高，已验证2万+阅读）**
- 核心公式：「大家以为A，其实B」——颠覆共识，让人忍不住点进来反驳或验证
- 示例：「宝马砍掉所有国产纯电，最慌的不是特斯拉」
- 示例：「"半价理想"这个称号，可能要换人了」
- 示例：「便宜的电车，反而卖不动了」
- 示例：「理想只会做增程？这个标签该撕了」
- **关键：反差越大，流量越高。** 用事实数据撑住反差，不是瞎编。

**1. 冲突反转型（爆率高）**
- 用角色卡的方式写：先给判断，再用故事/比喻/画面支撑
- 示例：「26万的Model Y，不值」——直接判断，争议性引流量
- 示例：「L8砍掉第三排，反而更想买了」——反直觉

**2. 个人体验型**
- 从「我」的经历出发
- 示例：「我朋友买了台理想ONE，全办公室笑话他」
- 示例：「去店里看了L8，说几个网上没人提的细节」

**3. 历史类比型**
- 用过去的事件映射当下
- 示例：「6年前嘲笑蔚来的人，今天在嘲笑谁？」
- 示例：「特斯拉就是几年前的BBA」

**4. 好奇心钩子型**
- 制造信息缺口
- 示例：「特斯拉只剩最后一张牌了」
- 示例：「L8最值钱的配置，90%的人不知道」

**5. 搜索截流型（SEO友好）**
- 直接回答用户搜索意图
- 示例：「Model Y值得买吗？一篇讲清楚」
- 示例：「26万SUV怎么选？真实车主告诉你」

**标题铁律：**
- 不超过20字（小红书标题显示截断）
- 不用「深度解析」「全面分析」「一文读懂」（小红书用户不点）
- 不套公式模板（如「数字+悬念」「emoji+人群标签」）——这些会让标题看起来像批量生产的

### Step 3：生成封面图prompt

封面图是小红书的「第一入口」。用户先看到图，再看标题。图不行，标题再好也没用。

**封面图类型（按效果排序）：**

**A. 实拍图+文字标注（最佳）**
如果用户有实车/实品照片：
```
HTML模板：实拍照片为底，左上角放品牌logo，右下角放价格/核心卖点大字，
底部放一行小字「村长不开车」水印。整体风格简洁，信息量大。
```

**B. 对比图（第二佳）**
两台车/两个产品左右对比：
```
HTML模板：左右分屏，左边产品A+价格+3个卖点，右边产品B+价格+3个卖点，
中间大字「VS」，顶部标题「到底选哪个？」。配色用产品官方色。
```

**C. 数据图（信息量型）**
把核心数据可视化：
```
HTML模板：深色背景，核心数据用大号亮色字体突出（如「29.88万」），
旁边配小字说明，底部放产品图。风格像科技发布会PPT。
```

**D. 金句图（传播型）**
把文章最犀利的一句话做成图：
```
HTML模板：纯色背景（黑/白/品牌色），中间大字金句，
底部小字出处「——村长不开车」。极简风格，像名言海报。
```

**封面图生成流程：**
1. 根据文章类型选择模板（对比/数据/金句/实拍标注）
2. 填入具体数据
3. 用浏览器渲染HTML → 截图（1080×1440，小红书3:4比例）
4. 保存为图片，用于小红书发布

**封面图配色方案：**
- 汽车类：深蓝(#1a1a2e) + 红色强调(#ff6b6b) + 金色(#ffd93d)
- 3C类：深灰(#0f0f0f) + 蓝色强调(#00d2ff) + 白色
- AI/科技：深紫(#16213e) + 绿色强调(#4ecdc4) + 白色
- 对比类：左黑右白，中间彩色VS

### Step 4：正文结构优化

小红书长文（800-2000字）和短文（300-800字）结构不同。

**长文结构（深度分析/产品评测）：**
```
第1段（2-3句）：核心结论 + 我为什么关注这件事（hook）
第2段（5-8句）：最重要的发现/数据/对比
第3段（5-8句）：第二个发现/数据/对比
第4段（5-8句）：第三个发现/个人体验
第5段（2-3句）：我的判断 + 金句收尾
```

**短文结构（快速反应/观点表达）：**
```
第1段（2-3句）：核心结论 + 为什么说这个
第2段（3-4句）：最重要的1个发现/数据
第3段（2-3句）：我的判断 + 金句收尾
```

**通用规则：**
- 第一句话必须有hook（让人想读第二句）
- 每3-4句检查：这句话是「我」在说话，还是匿名分析师在说话？
- 金句放最后一段（截图传播用）
- 超过1200字的内容用图片承载（数据图、对比图、实拍图）

### Step 5：搜索关键词植入

小红书搜索占流量的40-50%。关键词植入是SEO的核心。

**关键词来源：**
- 品牌名（蔚来、理想、小鹏、比亚迪、华为）
- 车型名（ES8、L8、YU7、GX）
- 价格区间（20万SUV、30万纯电、50万豪华）
- 竞品对比词（vs、对比、怎么选、哪个好）
- 用户痛点词（值得买吗、后悔吗、真实感受、优缺点）
- 场景词（家用、通勤、长途、带娃）

**植入位置（按权重排序）：**
1. **标题**：必须包含1-2个核心关键词
2. **正文前2行**：必须包含品牌名+品类词
3. **话题标签**：5-8个，从核心词到长尾词
4. **正文中间**：自然出现3-5次关键词
5. **图片OCR**：封面图上的文字也会被搜索引擎索引

**话题标签模板：**
```
#{品牌名} #{车型名} #{品类词} #{价格区间} #{场景词} #{热点词}
示例：#理想L8 #理想汽车 #30万SUV #家用SUV推荐 #大五座 #2026新车
```

### Step 6：发布时间策略

**发布会/热点事件的发布节奏：**

| 时间点 | 发什么 | 目的 |
|--------|--------|------|
| 发布会当天（0-2小时） | 300字快速反应帖 + 现场截图/直播截图 | 抢第一波流量 |
| 发布会当天（4-8小时） | 500字观点帖 + 对比图封面 | 深度一点的第二波 |
| 发布会后1-3天 | 800字深度帖 + 数据图封面 | 搜索截流（用户主动搜） |

**关键：不是只发一条，而是分3次发。**
- 第1条抢时效（流量型）
- 第2条给观点（互动型）
- 第3条做深度（搜索型，长尾流量）

**最佳发布时间：**
- 工作日：12:00-13:00（午休）、18:00-20:00（下班路上）、22:00-23:00（睡前）
- 周末：10:00-11:00、15:00-16:00、20:00-22:00

## ⚠️ 风格红线（2026-06-14教训）

用户明确拒绝了外部爆款公式工具（dbs-xhs-title的75个公式、write-xiaohongshu的S.L.R.A.模型、xhs-writer的情感转化框架）。原因是这些工具生成的内容有明显的「公式感」——用户一眼能看出是套模板。

**正确做法：** 用 writing-style skill 的「观察者型行业老兵」角色卡写内容，xhs-adapter 只负责**平台适配层**（标题长度、封面图、关键词、发布时间），不干预写作风格。

标题优化不是套公式，是**在角色卡的说话方式基础上，适配小红书的展示规则**（20字以内、需要有「人称」或「数字」、不用「深度解析」等公众号词）。
