# 事实核验表格模式

## 何时使用

写完文章后、发布前，用结构化表格逐项核验关键事实。比叙述式质检报告更直观、更不容易漏检。

## 表格格式

```markdown
| 事实点 | 来源 | 状态 |
|--------|------|------|
| 具体数字/事件1 | 来源URL或媒体名 | ✅/🟡/❌ |
| 具体数字/事件2 | 来源URL或媒体名 | ✅/🟡/❌ |
```

## 操作流程

1. **提取**：从正文中提取所有具体数字（价格、销量、营收、时间、型号等）
2. **搜索**：对每个数字用 web_search 找至少2个独立来源
3. **比对**：来源之间是否一致？不一致时分析统计口径差异
4. **标注**：
   - ✅ = 多源一致，可采信
   - 🟡 = 有冲突或仅单源，需标注"据XX估算/报道"
   - ❌ = 无法验证或已证伪，必须删除或替换
5. **修正**：❌项必须在发布前修正，🟡项必须加限定语

## 与传统质检的区别

- 传统L0质检：叙述式报告，容易遗漏
- 表格模式：逐项打勾，一目了然，适合快速交付
- 建议：**快速交付场景用表格，全流水线质检用L0-L5**

## 适用场景

- 用户急着要文章、没时间跑完整3-agent质检
- 热点文章时效性强，需要快速发布
- 作为完整质检的前置步骤（先过表格，再跑L0-L5）
