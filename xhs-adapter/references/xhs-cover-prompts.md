# 小红书封面图生成指南

## 通用规格
- 尺寸：1080×1440（3:4比例，小红书推荐）
- 格式：PNG/JPG
- 字数：封面图上的文字不超过30字
- 水印：右下角「村长不开车」，低透明度

## 四种封面类型

### A. 对比型（产品对比）
适用：两个产品对比、选择困难、VS场景
模板：`templates/cover-comparison.html`

**修改方法：**
1. 替换 `.title` 的标题文字
2. 替换两个 `.product` 的名称、价格、卖点
3. 替换 `.verdict` 的总结语
4. 背景色/强调色可根据品牌调性调整

**示例prompt（用于AI生成）：**
```
生成一张小红书封面图，尺寸1080x1440。
深色背景（#1a1a2e），左右分屏对比布局。
左侧：「理想L8」，价格「30万起」，三个卖点：五座联排零重力、800V全主动悬架、四颗激光雷达。
右侧：「理想L9」，价格「45万起」，三个卖点：六座三代同堂、800V全主动悬架、5米2旗舰尺寸。
中间大字「VS」用金色。
顶部标题：「L8砍掉第三排，反而更想买了？」
底部小字水印：「村长不开车」
风格：科技感、简洁、信息密度高。
```

### B. 数据型（核心数据突出）
适用：销量数据、价格对比、配置参数
模板：`templates/cover-data.html`

**修改方法：**
1. 替换 `.label` 的数据类型
2. 替换 `.big-number` 的核心数字
3. 替换 `.context` 的说明文字
4. 替换 `.detail` 的三个数据点

**示例prompt：**
```
生成一张小红书封面图，尺寸1080x1440。
纯黑背景，中央突出大字「2.2万台」（蓝色#00d2ff，180号字）。
上方小字「月销量」（灰色）。
下方说明：「蔚来ES8 连续5个月 大型SUV销冠」
底部三个数据点：29.88万（租电起售价）、4000+（换电站）、5年（免费换电）
风格：数据可视化、科技发布会风格、极简。
```

### C. 金句型（传播向）
适用：犀利观点、记忆锚点、争议判断
模板：`templates/cover-quote.html`

**修改方法：**
1. 替换 `.quote` 的金句文字
2. 替换 `.source` 的出处
3. 替换 `.context` 的背景说明
4. 强调词用 `.em` 样式（红色）

**示例prompt：**
```
生成一张小红书封面图，尺寸1080x1440。
深灰背景（#111），中央大字金句：「与其给三个人凑合坐，不如让两个人躺着」
「凑合坐」和「躺着」用红色（#ff6b6b）强调。
金句下方一条金色短横线。
横线下小字：「—— 村长不开车」
底部灰色小字：「理想L8 从六座改五座，不是减配，是换赛道」
左上角一个大号引号「"」作为装饰（低透明度）
风格：名言海报、极简、高级感。
```

### D. 反应型（快速发帖）
适用：发布会当天快速反应、热点事件评论
无固定模板，用发布会截图/直播截图 + 手写标注

**处理方法：**
1. 从发布会直播中截取关键画面
2. 用红色箭头/圈标注关键信息
3. 顶部加一行大字标题
4. 底部加水印

## 配色方案

| 品类 | 背景色 | 主强调色 | 辅强调色 |
|------|--------|---------|---------|
| 汽车 | #1a1a2e（深蓝） | #ff6b6b（红） | #ffd93d（金） |
| 3C | #0f0f0f（深灰） | #00d2ff（蓝） | #fff（白） |
| AI/科技 | #16213e（深紫） | #4ecdc4（绿） | #fff（白） |
| 对比 | #111（黑） | #ff6b6b（红） | #4ecdc4（青） |

## 生成流程

```
1. 选择封面类型（A/B/C/D）
2. 读取模板HTML
3. 替换占位符为实际内容
4. 浏览器渲染 → 截图（1080×1440）
5. 保存到 /tmp/xhs-cover-{类型}.png
```

**浏览器截图命令：**
```python
# 用computer_use工具
# 1. 打开HTML文件
# 2. 设置窗口大小1080×1440
# 3. 截图保存
```

或用已有的 `scripts/gen_xhs_images.py` 脚本。
