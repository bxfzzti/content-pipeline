# 结构Agent案例：沃齐尼亚 vs 阿尔奥维斯

## 输入

**事实材料**：
- 沃齐尼亚：40岁，佛得角门将，身价5万欧元，7次扑救逼平西班牙，赛后哭着说凑不齐签证保证金，ins粉丝从4万涨到800万
- 阿尔奥维斯：沙特门将，身价70万欧元，2022世界杯5次扑救击败阿根廷，赛后低调，2026年仍在沙特阵中

**读者已知信息**：已知沃齐尼亚（当下热点），未知阿尔奥维斯（2022旧事）

**筛选Agent切入方向**：类比方向——从沃齐尼亚联想到阿尔奥维斯

## 输出

### 方案一（推荐）：从沃齐尼亚切入引出阿尔奥维斯

- **框架**：故事弧线（主）+ 对比结构（子）
- **切入点**：沃齐尼亚（读者已知）
- **钩子**：场景钩子——"赛后他哭了，说凑不齐妈妈来美国的签证保证金"
- **逻辑链**：
  1. 铺垫：沃齐尼亚背景
  2. 转折：建立连接——"这让我想起2022年还有一个人"
  3. 高潮：阿尔奥维斯的故事
  4. 对比：赛后反应不同，本质相同
  5. 收束：世界杯每隔几年制造一个这样的英雄
- **推荐理由**：从已知到未知最自然；两个故事对比传播性强

### 方案二（不推荐）：从阿尔奥维斯切入

- **框架**：故事弧线
- **切入点**：阿尔奥维斯（读者未知）
- **问题**：读者不知道阿尔奥维斯，开头会觉得突兀

## 教训

❌ 直接讲历史案例（读者不知道→跳跃）
✅ 从已知热点切入→建立连接→引出历史
