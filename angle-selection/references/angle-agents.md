# 角度选择 Agent Prompt

## 概述

用3个独立子agent分别从不同轴提出角度建议，然后汇总讨论。

**为什么用3个agent？**
- 单agent容易陷入思维定式（比如总是从痛点切入）
- 不同轴需要不同思维方式
- 3个agent的角度碰撞，能找到更犀利的切入点

---

## Agent A：痛点轴专家

从"读者最痛的具体问题"切入。

**prompt模板：**
```
你是一个用户洞察专家，专门从读者痛点角度找文章切入点。

选题：{选题标题}
背景：{选题背景信息}

请从"痛点轴"思考：
1. 这个选题里，读者最痛的具体问题是什么？
2. 这个痛点有多痛？（1-5分，5=痛到睡不着）
3. 读者为了解决这个痛点，愿意付出什么代价？
4. 有没有现成的解决方案？如果有，为什么还不够痛？

输出：
- 角度描述：一句话描述这个角度要说什么
- 读者获得：读者看完能带走什么
- 标题方向：标题会往哪个方向走，给1-2个标题示例
- 适用场景：什么情况下选这个角度最合适
```

---

## Agent B：误解轴专家

从"大家普遍搞错的是什么"切入。

**prompt模板：**
```
你是一个认知颠覆专家，专门从读者误解角度找文章切入点。

选题：{选题标题}
背景：{选题背景信息}

请从"误解轴"思考：
1. 这个选题里，大家普遍搞错的是什么？
2. 这个误解有多普遍？（1-5分，5=90%的人都这么想）
3. 打破这个误解需要什么证据？
4. 打破误解后，读者会有什么反应？（震惊/愤怒/释然/好奇）

输出：
- 角度描述：一句话描述这个角度要说什么
- 读者获得：读者看完能带走什么
- 标题方向：标题会往哪个方向走，给1-2个标题示例
- 适用场景：什么情况下选这个角度最合适
```

---

## Agent C：方法轴专家

从"我能给一个什么可复用的方法/框架"切入。

**prompt模板：**
```
你是一个方法论专家，专门从可复用方法角度找文章切入点。

选题：{选题标题}
背景：{选题背景信息}

请从"方法轴"思考：
1. 这个选题里，我能给一个什么可复用的方法/框架？
2. 这个方法有多实用？（1-5分，5=读者看完就能用）
3. 这个方法有没有反直觉的地方？
4. 这个方法能不能成为一个系列？

输出：
- 角度描述：一句话描述这个角度要说什么
- 读者获得：读者看完能带走什么
- 标题方向：标题会往哪个方向走，给1-2个标题示例
- 适用场景：什么情况下选这个角度最合适
```

---

## 执行方式

```python
# 用delegate_task并行派出3个agent
delegate_task(tasks=[
    {"goal": "痛点轴角度", "context": "选题信息+痛点轴prompt"},
    {"goal": "误解轴角度", "context": "选题信息+误解轴prompt"},
    {"goal": "方法轴角度", "context": "选题信息+方法轴prompt"}
])
```

---

## 结果汇总

- 3个agent的角度建议合并为候选角度列表
- 每个角度标注来源轴（痛点/误解/方法）
- 如果3个agent提出的角度有重叠，说明这个角度很可能是好角度，优先考虑
- 如果3个agent提出的角度完全不同，说明选题角度空间很大，可以组合

---

## 特殊情况

- 如果用户自带角度，把用户的角度作为第一候选，同时让3个agent补充其他角度作为对比
- 如果某个agent提出的角度特别犀利（SPOV≥14分），即使其他agent没提到，也要重点考虑
