# writing-draft

接收 framing-article 输出的写作思路（定调+引用块+论点大纲），逐层证成。**只写正文，不自检、不发布。**

## ⚠️ 动笔前必须确认框架已就位（2026-06-15 教训）

**用户批评：「写的全是垃圾 东拼西凑……我们上午分析过零跑那篇文章为什么写得好 你完全给忘记了」**

原因：跳过了 framing-article 的步骤（标题→核心论点→支柱→论点结构），直接开始写正文。结果论点之间没有逻辑链条，各说各的。

**铁律：动笔前必须确认以下五项已就位，缺一不可：**
1. ✅ **事实已搜集够**——关键数字、关键人物、关键细节都有出处（2026-06-17新增）
2. ✅ 标题已定（有反差感的那句话）
3. ✅ 核心论点已拆（从标题拆出的一句话判断）
4. ✅ 支柱已找（能撑住全文的类比/事实/参照物）
5. ✅ 论点结构已规划（每个论点都挂在支柱上）

**如果这五项没有就位，禁止开始写正文。** 退回补充。

**⚠️ 事实搜集是第一步（2026-06-17 教训）：**
AI没有"我跟这个话题之间发生了什么"的认知流程。接到选题后，第一步是搜索事实：
1. 这个事到底是个什么事？关键数字、人物、细节
2. 各方对它的观点是什么？
3. 从中抽取可用信息

搜够了再写，搜不够不动笔。详见 `writing-style` 的"事实补充驱动"章节。

**自检方法：** 把文章的4个论点列出来，问自己「这4个论点之间有没有逻辑链条？」如果论点之间可以随意调换顺序，说明没有支柱，文章是散的。

## 写作方向选择：To C vs To B（动笔前必须确认）

同一篇选题，写给谁看完全不同。**在 framing-article 阶段就要确认方向，不确认不动笔。**

### To C（面向消费者）

读者：潜在购车者、普通消费者
核心问题：「这车适不适合我家？」
写法：
- 场景化叙述（带老人孩子出行、全家自驾游、接送客户）
- 个人体验视角（「我第一次坐进去的时候…」）
- 优缺点都说（建立信任，不吹不黑）
- 购买建议按预算/需求分层
- 结尾有互动引导（「评论区聊聊你家情况」「私信我聊落地价」）
标题风格：决策型、对比型、问题解决型
典型标题：「25万买MPV只有两个选择」「5个优点3个槽点，看完再决定」

### To B（面向行业）

读者：行业从业者、分析师、投资者
核心问题：「这个品牌的策略/格局是什么？」
写法：
- 分析型节奏（先给判断再补论据）
- 行业数据驱动（财报、销量、竞品对比）
- 战略视角（品牌定位、竞争格局、市场趋势）
- 不需要互动引导
标题风格：判断句、洞察型
典型标题：「零跑的半价哲学还能走多远」「D99最大的对手不是MEGA」

## 先选框架，再写正文（强制）

写消费决策型、种草型、横评对比型内容时，在动笔前必须先加载 `种草内容方法论` 选择框架：

1. 确认选题类型（单产品/横评/种草/观点）
2. 选框架：A竞品对比 / B踩坑反思 / C单品评测 / D观点输出
3. 套对应模板
4. 参考15条写作心法检查格式
5. 选标题公式

**不做这个步骤就直接动笔 = 自由发挥，不认可。**

## 写作风格底色（村长不开车风格）

一个有行业判断力的消费者，带用户用内部视角做消费决策。不装、不演、不高高在上。

**核心原则：**
- 口语化优先：把"因此""然而""值得注意的是"换成人话
- 人称用"我"：不是"我们来分析一下"，是"我先说一个判断"
- 知识是顺手掏出来的：不是"下面我来科普"，是"说到这个顺便提一句..."
- 先给判断再补论据：每个段落的核心观点必须在段首亮出
- 每篇让人能做一个决定：读完知道该买/不买/等/换，或者至少获得一个新认知

**绝对禁用：** "首先其次最后""综上所述""值得注意的是""不难发现""让我们来看看""说白了""这意味着""本质上""换句话说""不可否认"

## 写作节奏模式选择

根据选题类型选择不同的写作节奏。两个模式都是村长不开车底色，但节奏和结构偏好不同。

### 模式A：快节奏型（默认）

适合：单产品体验、个人感受型、短评快评

- **短句为主：** 连续3句以上独立成段？合并相邻短句
- **段落短小：** 自然段落2-3句，需要时才单句成段
- **全文独立成段不超过5次**
- **用冒号的场景：** 不用冒号段落、不用破折号开头、双引号用「」替代
- **数字要具体：** 不写"加速很快"，写"5.4米转弯半径比高尔夫还小"

**引用块定调法则：** 最强的那张牌开局就出。如果有一个足够强的文化/历史类比，直接放在正文第一段当透镜，不当结尾彩蛋。


### 模式B：分析型（参考黄海风格）

适合：行业格局分析、竞品横评、品牌战略解读、趋势判断

核心句式节奏：**先给判断，再补论据。**

每一段的展开顺序：
```
判断 → 数据 → 解读
```
不铺垫，不堆背景。第一句就把观点亮出来，后面的内容都是用来支撑这个判断的。

**段落节奏：**
- 段落可以更长，3-5句自然段，不强行切短
- 节奏更稳，不追求高频爆点
- 每段只放一个最有力的数字，不堆数据

**克制用数字原则：**
- 每个数字只用来支撑一个论点，不存在「顺便也列一下」的数字
- 一篇文章3-5个关键数字足矣，超过则稀释
- 数字放在判断之后、解读之前："L9毛利率25%，i6只有10%。每卖一台L9赚的钱顶4-5台i6。"

**跨段落结构统一原则：**
- 如果文章覆盖多个品牌/案例，每个段落用相同的结构节奏
- 读者读完第一个就知道后面怎么读，阅读负担低
- 例：品牌A（主销车型→价格带→问题→尝试→判断）→ 品牌B（一样的节奏）

**用商业逻辑作为分析透镜：**
- 从定价策略、品牌定位、竞争格局切入，不是从技术参数切入
- 写"为什么理想一定要死磕高端"，不写"理想的悬挂跟竞品有什么区别"
- 技术参数可以作为论据出现，但不作为分析框架

**绝对禁用：** "首先其次最后""综上所述""值得注意的是""不难发现""让我们来看看""说白了""这意味着""本质上""换句话说""不可否认"

## 正文结构

```
【开篇引用块】一行引用，全文定调
  ↓
【正文第一段】如果有关键类比，在这里甩出来。读者从这里进入文章视角
  ↓
【论点1】证成定调的一个角度
    - 一个核心观点
    - 一个最有力的例子/场景
    - 一句收住（回拷定调）
  ↓
【论点2】证成定调的另一个角度
    - 同上
  ↓
【论点3-4】继续证成
    - 同上
  ↓
【结尾金句】回拷定调，有重量感（可短句独立成段）
```

**注意：** 段落不要被打断。自然段落2-4句在一起，需要强调时才用单句独立成段。全文独立成段不超过5次。

## 写作密度检查

每写完一个论点，立即检查：
- 这段在说一个观点还是两个？两个则拆分或删减
- 例子只留最有力的一个，平行例子全砍
- 如果读起来觉得"在绕"→立即精简
- 转场一句带过，不使用固定模板词

**一个段落只装一个核心观点 + 一个最有力的例子 + 一句收住。不装第三样东西。**

## 输出格式

输出完整的正文 markdown（含引用块+标题+内容+收尾金句）。

**不加固定尾部。** 文章写完直接结束。需要署名就用最小形式：
```
—— 作者名
```

## ⚠️ To C vs To B 写法区分（2026-06-25 教训）

用户明确指出："三篇零跑写的都不错，但它是面向汽车行业从业者或者面向零跑公司来写的。面向真实的消费者……让他们对这辆车感兴趣，从而愿意给我发私信、发评论。"

**两套完全不同的写法：**

| 维度 | To B（行业分析） | To C（消费者导向） |
|------|-----------------|-------------------|
| 读者 | 行业从业者、媒体、投资人 | 真实购车者、消费者 |
| 关心什么 | 战略、市场格局、品牌定位 | 这车适不适合我家 |
| 语言风格 | 分析框架、行业术语 | 场景化、家庭日常 |
| 互动钩子 | 行业讨论、观点碰撞 | "你家情况选哪个""落地多少钱" |
| 结尾 | 行业判断、趋势预判 | 互动引导（评论/私信） |

**To C写作核心原则：**
1. **场景化**：用家庭场景讲车（带老人孩子出行、全家自驾游、接送客户）
2. **代入感**：让读者觉得"这就是在说我"
3. **互动钩子**：结尾必须引导评论或私信（"评论区聊聊你家情况""私信我聊落地价"）
4. **优点+槽点都讲**：不吹不黑建立信任，消费者更信"有缺点的推荐"
5. **购买建议要具体**：按预算/需求分层，不是泛泛而谈

**判断标准：** 写完问自己——这篇文章是让读者"理解行业"还是帮读者"做决定"？前者是To B，后者是To C。

## 配图（正文完成后必做）

**所有文章，不分题材，正文完成后必须走配图流程。** 哪怕是指标分析/行业评论型文章，也至少配1-2张相关场景图或产品图。无配图不交付。

**完整流程（五步）：**

1. **拆文章定需求** — 明确哪些章节需配图（开箱/外观/功能/场景/细节），一一对应
2. **素材调研（核心，不可跳过）** — 微博/小红书搜 `产品名`，看大V和用户的实拍风格；下载官网产品图；记录拍摄角度/光线/背景/构图
3. **决定用谁的图** — 用户实拍够好直接用并标注；有参考价值则二次创作；实在没有才AI生图
4. **二次创作/AI生图** — 基于调研学来的风格写prompt，复现真实拍摄感，不凭空创造
5. **插入文章** — 写一段→插对应图→再写一段→再插对应图，不堆末尾

**核心原则：先调研，不调研不生图。跟用户学，跟买过的人学，跟评测大V学。**

详细工作流参见 `skills/image-gen/README.md`

## 写作方向：To C vs To B（2026-06-25 教训）

用户明确指出：「你写的都是面向汽车行业从业者或者面向零跑公司来写的，面向真实的消费者，他们怎么看待这辆车？」

**两种写法的区别：**

| 维度 | To B（行业分析） | To C（消费者视角） |
|------|-----------------|-------------------|
| 读者 | 从业者、分析师、媒体 | 买车的人、家庭用户 |
| 关心什么 | 战略、格局、市场份额 | 适不适合我家、多少钱、有什么槽点 |
| 语言 | 分析师术语、行业框架 | 场景化、口语化、「我带着老婆孩子去试驾」 |
| 互动点 | 「这个分析有道理」 | 「我家情况也这样，选哪个？」|
| 标题风格 | 「零跑的半价哲学还能走多远」 | 「25万买MPV只有两个选择」 |

**铁律：** 用户说「面向消费者」「To C」「让读者私信/评论」时，必须用场景化写法：
- 用家庭场景讲车（带老人孩子出行、全家自驾游）
- 优缺点都说（建立信任）
- 结尾有互动引导（「评论区聊聊你家情况」「私信聊落地价」）
- 不能用行业分析框架（市场份额、品牌战略、竞争格局）

**在 framing-article 阶段就要确认写作方向。** To C文章的支柱不是行业类比，是「这个场景你一定经历过」。
